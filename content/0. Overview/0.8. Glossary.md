## Which terms do you need before Chapter 2?

Ten carry most of what Chapters 0 to 2 assume: [agent](#agent), [agentic loop](#agentic-loop), [tool](#tool), [session](#session), [ADK](#adk), [MCP](#mcp), [A2A](#a2a), [guardrail](#guardrail), [evaluation](#evaluation), and [doctor](#doctor). If those ten read as familiar words rather than unknown names, you are ready for Setup.

## What does each course term mean?

Alphabetical, so use your browser's find. Each entry links to the section that owns the term, which is also where the narrower vocabulary around it is defined — product names such as Ollama, Tempo, Loki, and Grafana are in [0.4. Ecosystem]({{< relref "/0. Overview/0.4. Ecosystem.md" >}}) instead, one row each.

- <a id="a2a"></a>**A2A**: Protocol for discovering agents and exchanging tasks across processes. [3.6. A2A]({{< relref "/3. Capabilities/3.6. A2A.md" >}})
- <a id="adk"></a>**ADK**: Google's Agent Development Kit — runner, sessions, tools, telemetry. [2.0. Concepts]({{< relref "/2. Agents/2.0. Concepts.md" >}})
- <a id="agent"></a>**Agent**: A model-driven loop that selects tools or delegates work toward a goal. [0.1. Agents]({{< relref "/0. Overview/0.1. Agents.md#what-is-an-ai-agent" >}})
- <a id="agentgateway"></a>**agentgateway**: The proxy in front of agents, models, and tools that enforces policy and auth. [5.0. Gateway]({{< relref "/5. Gateway/5.0. Gateway.md" >}})
- <a id="agentic-loop"></a>**agentic loop**: The decide-act-observe cycle an agent repeats until it can answer. [0.1. Agents]({{< relref "/0. Overview/0.1. Agents.md#what-is-the-agentic-loop" >}})
- <a id="agentops"></a>**AgentOps**: Operating agents as production software: capabilities, guardrails, HITL, lifecycle. [0.3. AgentOps]({{< relref "/0. Overview/0.3. AgentOps.md#what-is-agentops" >}})
- <a id="clusterip"></a>**ClusterIP**: A Service address reachable only inside the cluster. [6.4. Platform Tools]({{< relref "/6. Platform/6.4. Platform Tools.md" >}})
- <a id="doctor"></a>**doctor**: The staged check that verifies the tools one learning tier needs. [1.0. System]({{< relref "/1. Setup/1.0. System.md" >}})
- <a id="evaluation"></a>**Evaluation**: Repeatable measurement of behavior, trajectory, safety, or output quality. [4.4. Evaluations]({{< relref "/4. Quality/4.4. Evaluations.md" >}})
- <a id="gate"></a>**gate**: A deterministic signal whose failure always means a reproducible defect. [0.2. Evidence]({{< relref "/0. Overview/0.2. Evidence.md" >}})
- <a id="guarded-write"></a>**guarded write**: A state-changing tool needing human confirmation, committing mutation and audit row together. [3.1. Tools]({{< relref "/3. Capabilities/3.1. Tools.md" >}})
- <a id="guardrail"></a>**Guardrail**: Deterministic or model-assisted policy at an input, model, tool, or output boundary. [4.5. Guardrails]({{< relref "/4. Quality/4.5. Guardrails.md" >}})
- <a id="helm-chart"></a>**Helm chart**: A parameterized set of Kubernetes manifests installed as one named release. [6.2. Platform Install]({{< relref "/6. Platform/6.2. Platform Install.md" >}})
- <a id="image-digest"></a>**image digest**: The `@sha256:…` hash naming an image's exact bytes, which a tag cannot promise. [6.1. Containers]({{< relref "/6. Platform/6.1. Containers.md" >}})
- <a id="k3d"></a>**k3d**: A lightweight k3s cluster inside Docker on your laptop, so no cloud account is needed. [1.3. Kubernetes]({{< relref "/1. Setup/1.3. Kubernetes.md" >}})
- <a id="kagent"></a>**kagent**: CNCF Sandbox project that manages agents as Kubernetes custom resources. [6.0. Platform]({{< relref "/6. Platform/6.0. Platform.md" >}})
- <a id="kubernetes"></a>**Kubernetes**: The orchestrator that reconciles a cluster toward declared state; a **pod** is its unit. [6.0. Platform]({{< relref "/6. Platform/6.0. Platform.md" >}})
- <a id="kustomize-overlay"></a>**Kustomize overlay**: Patches layered onto a shared `base/`, so environments differ by a diff. [6. Platform]({{< relref "/6. Platform/_index.md" >}})
- <a id="mcp"></a>**MCP**: Model Context Protocol, for discovering and invoking tool or context servers. [3.3. MCP]({{< relref "/3. Capabilities/3.3. MCP.md" >}})
- <a id="networkpolicy"></a>**NetworkPolicy**: Kubernetes resource restricting pod reachability and egress. [6.5. Platform Gateway]({{< relref "/6. Platform/6.5. Platform Gateway.md" >}})
- <a id="opentelemetry-otel"></a>**OpenTelemetry (OTel)**: Vendor-neutral instrumentation and transport for all three signals. [7.1. Tracing]({{< relref "/7. Observability/7.1. Tracing.md" >}})
- <a id="otlp"></a>**OTLP**: The OpenTelemetry wire protocol (HTTP or gRPC) the app and gateway export through. [7.1. Tracing]({{< relref "/7. Observability/7.1. Tracing.md" >}})
- <a id="pii"></a>**PII**: Personally identifiable information, redacted before requests reach the model. [4.5. Guardrails]({{< relref "/4. Quality/4.5. Guardrails.md" >}})
- <a id="prompt-injection"></a>**prompt injection**: Attacker-controlled text that tries to override agent instructions. [5.5. Gateway Security]({{< relref "/5. Gateway/5.5. Gateway Security.md" >}})
- <a id="pvc"></a>**PVC (PersistentVolumeClaim)**: Persistent cluster storage that reattaches to replacement Pods. [6.6. Platform Delivery]({{< relref "/6. Platform/6.6. Platform Delivery.md" >}})
- <a id="registry"></a>**registry**: Where images are pushed and pulled; a local one lets k3d pull the bytes you built. [1.3. Kubernetes]({{< relref "/1. Setup/1.3. Kubernetes.md" >}})
- <a id="rwo"></a>**RWO (ReadWriteOnce)**: Read-write attachment from one node, not a distributed-write guarantee. [6.3. Platform Agents]({{< relref "/6. Platform/6.3. Platform Agents.md" >}})
- <a id="session"></a>**session**: Per-conversation runtime state, events and history, owned by the ADK runner. [2.4. Sessions]({{< relref "/2. Agents/2.4. Sessions.md#what-is-a-session" >}})
- <a id="skaffold"></a>**Skaffold**: One command that builds the image, pushes it, and applies the selected overlay. [6.2. Platform Install]({{< relref "/6. Platform/6.2. Platform Install.md" >}})
- <a id="slo"></a>**SLO**: Service Level Objective tied to an observable user outcome, such as 99% error-free requests. [4.3. Metrics]({{< relref "/4. Quality/4.3. Metrics.md" >}})
- <a id="spotlighting"></a>**spotlighting**: Marking untrusted tool output so the model treats it as data, not instructions. [4.5. Guardrails]({{< relref "/4. Quality/4.5. Guardrails.md" >}})
- <a id="token-budget"></a>**token budget**: A per-conversation cap that stops the next model call once its tokens are spent. [7.3. Costs]({{< relref "/7. Observability/7.3. Costs.md" >}})
- <a id="tool"></a>**Tool**: A typed function or remote capability an agent can invoke. [3.1. Tools]({{< relref "/3. Capabilities/3.1. Tools.md" >}})
- <a id="trace"></a>**Trace**: A correlated record of model, tool, gateway, and application work in one request. [7.1. Tracing]({{< relref "/7. Observability/7.1. Tracing.md" >}})
- <a id="trajectory"></a>**trajectory**: Which tools an agent called, with which arguments, in which order. [4.4. Evaluations]({{< relref "/4. Quality/4.4. Evaluations.md" >}})
- <a id="wif"></a>**WIF**: Workload Identity Federation — maps workload identity to cloud IAM without a static key. [6.5. Platform Gateway]({{< relref "/6. Platform/6.5. Platform Gateway.md" >}})
- <a id="wolfi"></a>**Wolfi**: The minimal Linux distribution the agent's runtime stage is built on. [6.1. Containers]({{< relref "/6. Platform/6.1. Containers.md" >}})
- <a id="workflow"></a>**Workflow**: A declared graph of steps used instead of an autonomous loop. [3.5. Workflows]({{< relref "/3. Capabilities/3.5. Workflows.md" >}})

## How should you use this page later?

- Come back whenever a chapter uses a word you could not explain to someone else; each entry gives you one line and the section that owns it.
- Keep it open in a second tab through Chapters 1 to 3, where most of the unfamiliar names arrive.
- Reopen it for Chapter 6, which introduces the densest run of new vocabulary — k3d, pod, Kustomize overlay, Helm chart, Skaffold, registry, image digest, Wolfi.

Continue to [1. Setup]({{< relref "/1. Setup/_index.md" >}}) when the ten starter terms read as familiar words rather than unknown names.
